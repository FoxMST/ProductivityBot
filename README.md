# ProductivityBot
*Задача 1* \
Реализация Echo-Bot, который возвращает текстовое сообщение введенное пользователем. Имеет две команды /help, /start.
Для того чтобы начать диалог в боте нужно везти команду /start или само сообщение.

Чтобы запустить бота со своего устройств, необходимо взять токен у @BotFather и добавить его в новый файл .env\
BOT_TOKEN=твой токен \
BOT_USERNAME=имя бота без@

После соберите проект через mvn clean package и запустите бота через консоль java -jar target\productivitybot.jar


Пример - Пользователь: Доброе утро \
Бот: Вы ввели: «Доброе утро»\
Пользователь: /start \
Бот: 👋 Привет! Я бот-продуктивность.
Напиши /help, чтобы увидеть команды.
