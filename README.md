# ProductivityBot

Telegram-бот для управления задачами. Поддерживает добавление, просмотр,
удаление и редактирование задач на выбранный день. Ведёт диалог пошагово,
с кнопками и возможностью отмены на любом шаге. Поддерживает несколько
пользователей одновременно.

---

## Запуск

1. Получите токен у [@BotFather](https://t.me/BotFather).
2. Создайте в корне проекта файл `.env`:
   BOT_TOKEN=ваш_токен
   BOT_USERNAME=имя_бота_без_@
   text
3. Соберите проект:
   mvn clean package
   text
4. Запустите:
   java -jar target/Proba-1.0-SNAPSHOT.jar
   text

После запуска в консоли появится `Бот запустился`.

## Задача 2. Добавление / просмотр / редактирование / удаление задач

Пошаговые диалоги с кнопками, отмена на любом шаге, хранение задач
в памяти (отдельный класс `TaskStorage`), поддержка нескольких
пользователей одновременно (у каждого чата своя сессия).

### Команды

| Команда          | Что делает                                 |
|------------------|--------------------------------------------|
| `/start`         | Приветствие                                |
| `/help`          | Справка                                    |
| `/add_task`      | Добавитыь задачу на сегодня                |
| `/show_tasklist` | Показать задачи за выбранный день          |
| `/edit_task`     | Редактировать задачу (текст)               |
| `/delete_task`   | Удалить задачу по ID или из списка на день |

На каждом шаге можно нажать **❌ Отмена** — черновик задачи уничтожается,
бот отвечает: *«Черновик задачи удален. Введите любую команду.»*

ID задачи — глобальный номер, не переиспользуется, начинается с 1.

### Пример: добавление задачи

Пользователь: /add_task
Бот: 📝 Введите текст задачи
[❌ Отмена]
Пользователь: Купить хлеб
Бот: ✅ Задача добавлена.
text

### Пример: отмена черновика

Пользователь: /add_task
Бот: 📝 Введите текст задачи
[❌ Отмена]
Пользователь: нажимает [❌ Отмена]
Бот: Черновик задачи удален. Введите любую команду.
text

### Технические детали

- **Хранение:** в памяти (`TaskStorage`), два индекса — `Map<Integer, Task>` и `Map<LocalDate, List<Task>>`
- **Состояния диалога:** enum `State` + `UserSession` на каждый чат
- **Мультипользовательский режим:** `Map<Long, UserSession>` — у каждого чата своя сессия
- **Java 25**, Maven, JUnit 5 (44 теста)
